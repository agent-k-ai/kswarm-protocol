# Provenance

This repository is published from a source tree, not developed here. Each commit
is one export of one source revision.

| Field | Value |
|---|---|
| Source ref | `v0.1.0-devnet.3` |
| Source tree | `e1ccbe1a0feea5caa9149b0572235a1d52786ae5` |

The source tree hash is the git tree object of the revision this export was cut
from. It identifies the exact input bytes without disclosing where they live.
The published tree is a filtered subset of that tree, so it does not hash to the
same value; `publish/` in the source repository holds the allowlist, the
transforms, and the templates that produce it.
